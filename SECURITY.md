# Security Policy

Please report suspected vulnerabilities through GitHub Private Vulnerability Reporting instead of opening a public issue. If private reporting has not yet been enabled, contact the project owner privately and do not publish exploit details.

Tora_MeshForge treats imported model files as untrusted. Reports should include the affected version, reproduction steps, impact, and a minimal non-sensitive fixture when possible. Do not include confidential models or textures.

Supported versions will be listed in GitHub Releases once the first public release is published. Until then, only the current `main` branch is evaluated for fixes.
