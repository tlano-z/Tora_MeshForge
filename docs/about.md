# このツールについて

[READMEへ戻る](../README.md)

Tora_MeshForgeは、高密度な静的3Dモデルを、比較して選べる軽量なFBXへ変換するWindows向けツールです。

単にポリゴン数を減らすだけでなく、軽量化で失われるUV、Base Color、表面の細かな陰影を再構成し、元モデルとの違いを確認できるところまでを一連の処理として自動化します。

## なぜこのツールが必要なのか

高密度モデルをリアルタイム用途へ持っていくには、通常、次のような作業と判断が必要です。

- リメッシュやポリゴン削減の設定を決める
- どこまで減らしても実用になるか、複数の結果を作って比べる
- 新しいメッシュに合わせてUVを作り直す
- 元の色を新しいUVへ移す
- 軽量化で失われた表面の凹凸を補う
- 輪郭、細い部位、UV、テクスチャの破綻を確認する
- FBXとして再読込できる状態に仕上げる

Blenderで一つずつ実行することもできますが、適切な設定を選び、結果を確認して再実行するには知識と時間が必要です。

Tora_MeshForgeは、この試行錯誤を「候補を指定して実行し、測定結果とプレビューから選ぶ」流れへまとめます。

## 手作業との違い

手作業では、設定、実行、確認、調整、再実行を候補ごとに繰り返します。本ツールでは、次の処理を同じ条件で連続実行します。

1. 元モデルを検査する
2. 指定した三角形数のメッシュを生成する
3. 新しいUVを生成して、可能な範囲で島をまとめる
4. 元モデルからBase Colorを再構成する
5. 元形状との差をNormalマップとして生成する
6. 形状、UV、テクスチャ、Normal、FBX再読込を検査する
7. 比較用の画像とHTMLを生成する

これにより、Blenderの各機能や細かな設定をすべて理解していなくても、一通りの軽量化と比較を実行できます。また、長い処理を一工程ずつ操作する必要がなく、途中経過と結果をGUIから確認できます。

## 2つの基本ワークフロー

### Quality Sweep

適切な三角形数が分からない場合のワークフローです。

50,000、25,000、10,000、5,000など、ユーザーが指定した複数の候補を生成し、元モデルとの形状差やBase Colorの誤差を測定します。候補は次の役割で提示されます。

- `Fidelity`: 元モデルとの形状差が最も小さい候補
- `Balanced`: 品質低下と三角形数削減の折衷点になる候補
- `Lightweight`: 測定と検証を完了した候補のうち最も軽いもの

これは、Voxel Sizeを自動探索する機能ではありません。指定された三角形数候補を同じ基準で作成・測定し、人が選びやすい状態にする機能です。

### Single Target Build

必要な三角形数が決まっている場合のワークフローです。

指定した一つの三角形数で、メッシュ、UV、Base Color、Shape Normal、比較HTMLを生成します。Quality Sweepで採用する三角形数を決めた後の再生成にも利用できます。

## リメッシュで行っていること

形状再構成の中心には、Blender標準のVoxel RemeshとCollapse Decimateを使用しています。独自のリメッシュ演算でBlenderを置き換えるものではありません。

本ツールでは、これらを次のように自動化しています。

- オブジェクトのScaleを適用してから処理する
- モデルの大きさに対する相対値としてVoxel Sizeを計算する
- 細かいVoxel Remeshで表面を再構成してから、指定三角形数へ削減する
- 法線を外向きに再計算する
- 境界エッジ、異常なエッジ、縮退面、連結状態を検査する
- 元モデルを変更せず、比較とベイクの参照元として保持する

リメッシュ処理そのものは、同じ設定を使えばBlender上で手動再現できます。本ツールの利点は、必要な設定と後続処理をまとめ、複数候補の生成と検査を繰り返し操作なしで実行できる点です。

## UVの再構成

Voxel Remesh後のメッシュには、元モデルのUVをそのまま利用できません。そのため、新しいメッシュ上でUVを作り直します。

面のつながりと曲率を利用して領域を作り、UV島を結合するたびに次の状態を検査します。

- 面積のないUVが発生していないか
- UVの重なりが許容範囲内か
- 角度の歪みが大きすぎないか
- 面積の伸縮が大きすぎないか

最小島数の目標は1ですが、品質条件を満たせない結合は行いません。人がパーツを理解して作るUVと同じものではありませんが、自動展開で細かな断片が大量に残る状態を減らし、後から確認しやすい配置を目指します。

## 見た目の再構成

新しいメッシュとUVに合わせて、元モデルからBase Colorを再投影します。

さらに、元の高密度形状と軽量メッシュの表面方向の差を、タンジェント空間のShape Normalとして生成します。これにより、ポリゴン削減で失われた細かな表面の陰影を補います。

Normalマップが補えるのは表面の陰影です。輪郭、落ちる影、視差、失われた細い形状そのものは復元できません。

## 自動で確認する項目

生成結果について、主に次の項目を検査します。

- 出力三角形数
- 単一サーフェスとして再構成されているか
- 開いた境界や異常なエッジがないか
- 縮退面がないか
- UVに有効な面積があるか
- UV重なりが許容範囲内か
- Base ColorとShape Normalの投影失敗が多すぎないか
- Normalの値と接線が有効か
- 出力FBXを再読込できるか
- テクスチャがMaterialへ接続されているか

Quality Sweepでは、元モデルと候補表面の距離、Base Colorの色差も測定します。

これらは明らかな失敗を見つけ、候補を比較するための検査です。自動チェックが通ったことだけで、用途に対する見た目の品質を保証するものではありません。

## 確認しやすい成果物

処理後はFBXとテクスチャだけでなく、次の確認資料も生成します。

- Geometry表示
- メッシュ表示
- Base Color表示
- Base ColorとShape Normalを使用したマテリアル表示
- 正面、側面、背面のプレビュー
- UV線のみの画像
- Base ColorとUV線を重ねた画像
- 元モデルと結果を並べた比較HTML
- 測定値、警告、処理ログ

Blenderを開いて一から比較環境を作らなくても、まずHTMLと画像から候補を絞り込めます。

## 適しているモデル

- AI生成の高密度な静的モデル
- 3Dスキャン由来の静的モデル
- ポリゴン数が過剰で、そのままリアルタイム表示に使いにくいモデル
- UVとBase Colorを含めて作り直したいモデル
- どの三角形数が妥当か、複数候補を比較したいモデル

## 現在の制限

- 対象は静的モデルです
- rig、animation、shape keyは出力へ引き継ぎません
- 人体や関節の変形を考慮したエッジループは生成しません
- 接触した部位や近接した薄い形状は、Voxel Remeshで結合・消失する場合があります
- UV島は形状から推定しており、部位の意味を理解して分割しているわけではありません
- 元モデルのRoughness、Metallic、Emission、Alpha、既存Normalは再構成しません
- Shape Normalは輪郭や失われた立体形状を復元しません

最終的な採用前には、比較HTMLに加えて、実際に使用するBlenderやゲームエンジンでも確認してください。

## このツールの位置づけ

Tora_MeshForgeは、熟練者による手作業のリトポロジーを常に上回ることを目的としたツールではありません。

一つのモデルへ時間をかけ、意味のあるエッジ構造や手作業のUVを作れば、より用途に合った結果を得られる場合があります。一方で、その作業には知識と時間が必要です。

本ツールは、専門的な操作と繰り返し試行の負担を減らし、静的モデルの軽量化、見た目の再構成、比較、確認までを一つの流れで行えるようにすることを目的としています。

> 高密度な静的3Dモデルの軽量化に必要な試行錯誤を自動化し、UV・Base Color・Shape Normalまで再構成した複数の候補を、測定結果とプレビューから選べるようにするツールです。
